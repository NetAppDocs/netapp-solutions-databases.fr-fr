= Flux de travail Google Cloud NetApp Volumes pour déployer une base de données Oracle 26ai à haute disponibilité
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Utilisez le stockage bloc iSCSI Google Cloud NetApp Volumes pour déployer une base de données Oracle 26ai à haute disponibilité avec Oracle Data Guard sur Google Compute Engine. Ce processus vous guide à travers les options de déploiement, le provisionnement de l'infrastructure, l'installation du logiciel Oracle et la configuration de la haute disponibilité, en tirant parti de la réplication au niveau du stockage de GCNV pour une initialisation accélérée de l'instance de secours.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Un"]link:gcnv-oracle-solution-architecture.html["Examiner l'architecture de la solution"]
[role="quick-margin-para"]
Comprenez l’architecture Google Cloud NetApp Volumes pour la haute disponibilité d’Oracle Database 26ai, y compris la conception du stockage bloc iSCSI GCNV, l’intégration de Data Guard et la topologie de stockage.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Deux"]link:gcnv-oracle-deployment-options.html["Examiner les options et les exigences de déploiement"]
[role="quick-margin-para"]
Comparez les niveaux de déploiement, du développement/test à la production HA, et confirmez les prérequis en matière d'infrastructure, d'accès et de logiciels.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Trois"]link:gcnv-oracle-access-and-apis.html["Vérifiez l'accès et les API"]
[role="quick-margin-para"]
Confirmez les accès requis, l'activation de l'API, les prérequis réseau et la synchronisation horaire.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-4.png["Quatre"]link:gcnv-oracle-provision-compute.html["Provisionner des instances Google Compute Engine"]
[role="quick-margin-para"]
Créez des machines virtuelles pour la base de données principale, la base de données de secours et l'observateur Fast-Start Failover.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-5.png["Cinq"]link:gcnv-oracle-provision-storage.html["Provisionner le stockage iSCSI GCNV"]
[role="quick-margin-para"]
Créez des pools de stockage GCNV et des volumes iSCSI, configurez le multipath et créez des groupes de disques ASM.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-6.png["Six"]link:gcnv-oracle-install-software.html["Installez Oracle Grid Infrastructure et Oracle Database 26ai"]
[role="quick-margin-para"]
Installez le logiciel Oracle Grid Infrastructure et Oracle Database 26ai sur les deux hôtes de base de données.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-7.png["Sept"]link:gcnv-oracle-primary-database.html["Créer la base de données principale"]
[role="quick-margin-para"]
Créez la base de données Oracle principale avec le stockage ASM et configurez Oracle Restart.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-8.png["Huit"]link:gcnv-oracle-standby-database.html["Créer la base de données de secours"]
[role="quick-margin-para"]
Initialisez la base de données de secours à l'aide de la réplication GCNV, des instantanés ou des clones, puis enregistrez-la auprès d'Oracle Restart. Tous les niveaux HA effectuent cette étape.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-9.png["Neuf"]link:gcnv-oracle-standby-finalize-dg.html["Finaliser la base de données de secours pour Data Guard"]
[role="quick-margin-para"]
Créez des journaux de restauration de secours, activez la restauration flashback, activez la réplication des journaux de restauration et vérifiez l'état de Data Guard. *Spécifique au niveau :* Requis uniquement pour le niveau Prod HA (Data Guard + FSFO).

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-10.png["Dix"]link:gcnv-oracle-data-guard.html["Configurer Data Guard Broker et Fast-Start Failover"]
[role="quick-margin-para"]
Activez le broker, créez la configuration Data Guard, activez FSFO et configurez l'observateur. *Spécifique au niveau :* Requis uniquement pour le niveau Prod HA (Data Guard + FSFO).
